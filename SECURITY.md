# Security Policy

## Supported Versions

Security fixes target the latest released version of `pcap-lens`.

## Reporting a Vulnerability

Please report security issues privately by email:

security@badita.dev

Do not open a public GitHub issue for vulnerabilities, malicious captures, or bypasses in the rule-matching engine.

## Capture Privacy

`pcap-lens` v1 is designed to run locally in the browser. Packet captures are not uploaded by the application.
